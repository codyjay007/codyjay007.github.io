## Event launch

1. Copy the complete repository folder to the event laptop and one backup
   drive. Do not copy only `index.html`.
2. Double-click `START_PROJECT_727.cmd` while offline.
3. Confirm the Project 727 Calibration screen appears.
4. Enter fullscreen, confirm sound, open the operator panel, then reset all
   progress.
5. Keep a second untouched copy of the folder and one backup Court packet with
   the operator materials.

If the browser blocks direct local files, serve the unchanged folder from a
local-only HTTP server and open `index.html` through `127.0.0.1`. No internet
connection is required.
