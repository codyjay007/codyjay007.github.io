# Project 727 — Event Runbook

Keep this file and all operator sheets hidden from the player.

## One week before

- [ ] Print every asset at 100% using `print/PRINT_GUIDE.md`.
- [ ] Rehearse the complete physical route in the actual rooms.

- [ ] Test the final lock repeatedly and prepare a hidden backup unlock method.
- [ ] Confirm the final box fits and the birthday card appears before the gift.

- [ ] Charge the laptop; disable notifications, updates, and sleep.
- [ ] Disconnect from the internet and launch `START_PROJECT_727.cmd`.
- [ ] Reset progress and confirm fullscreen, sound, and operator shortcut.
- [ ] Place Court packet in the living room.
- [ ] Place Table receipt in the kitchen.
- [ ] Put the sealed Room packet in the marked drawer.
- [ ] Place Origin packet in the primary bedroom.
- [ ] Check primary-closet map lighting.
- [ ] Close the guest bedroom and keep it unseen until Finale.
- [ ] Set and test the physical lock without exposing its digits.
- [ ] Put the birthday card before the Bvlgari box.
- [ ] Test warm-white lights and photograph the completed setup.

## During play

- [ ] Wait 2–3 minutes before offering Hint 1.
- [ ] Use all normal hints before a verbal nudge.
- [ ] Use operator solve only for a technical or physical failure.
- [ ] Never state, type, print, or display the final four lock digits.
