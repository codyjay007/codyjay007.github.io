# Project 727 — Ready-to-run static build

This version has no package manager or build step and remains fully offline-capable.

## Run

### Fastest
Double-click `index.html`.

### Recommended local server
From this folder:

```powershell
python -m http.server 7270
```

Then open:

```text
http://localhost:7270
```

## Player entry

- Identify the subject as `TINA`.
- No numeric login is required.
- Puzzle solutions remain in the private operator materials.

## Emergency controls

- Press `Ctrl + Shift + 9` to open the operator console.
- Or open `index.html?admin=727` / `http://localhost:7270/?admin=727`.
- The console can jump to any chapter, reset progress, and toggle sound.

## Reliability checklist

1. Test once in the exact browser and laptop used on the day.
2. Keep this entire folder copied to a USB drive or second laptop.
3. Disable notifications and automatic sleep.
4. Test every answer, hint, and operator jump.
5. Do not reveal the operator shortcut to the player.
